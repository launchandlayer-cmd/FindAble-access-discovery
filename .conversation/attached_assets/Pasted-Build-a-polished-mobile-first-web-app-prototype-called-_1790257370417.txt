Build a polished, mobile-first web app prototype called "FindAble".

CORE PURPOSE:
FindAble helps Deaf people find institutions and services where communication is accessible to them.

The main problem being solved is that Deaf people may struggle to know which schools, healthcare facilities, government offices, businesses, and other institutions are prepared to communicate with them.

IMPORTANT:
This is NOT primarily a Kenyan Sign Language learning app.
The core journey is:
Find a service → search for accessible institutions → compare accessibility information → view institution details → contact/navigate to the institution.

Create a realistic, polished prototype that can be demonstrated in a browser. No backend, authentication, database, or real API is necessary. Use realistic sample data and make all navigation functional on the frontend.

DESIGN:
- Mobile-first design.
- Make it look like a modern accessibility-focused startup.
- Clean, professional, welcoming interface.
- Strong readability and accessible contrast.
- Rounded cards and buttons.
- Clear visual hierarchy.
- Use simple accessibility-related icons where appropriate.
- Avoid excessive animations or decoration.
- Make the interface feel suitable for a real product, not a generic dashboard.
- The primary viewport should resemble a modern smartphone.
- Make the app responsive on desktop as well.

ACCESSIBILITY:
- Use readable font sizes.
- Use clear labels.
- Don't rely only on color to communicate information.
- Use icons alongside text where useful.
- Make buttons large enough to tap comfortably.
- Maintain strong contrast.

TECHNICAL:
- Build with a clean component structure.
- Use React if appropriate.
- Keep everything frontend-only.
- No authentication.
- No database.
- No external API keys.
- Use sample/mock data.
- Ensure the app runs immediately in Replit.
- Make the interface responsive.
- Make navigation and interactions actually work.

The finished result should clearly communicate that FindAble is an accessibility-discovery platform for Deaf people, not a KSL learning platform.
